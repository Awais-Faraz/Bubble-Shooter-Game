# Premium Bubble Shooter (Python + Pygame)

A complete bubble shooter with **100 levels**, glossy procedurally-drawn graphics, particle effects,
6 power-ups, star ratings, JSON save system, and synthesised music/sound effects.
No images, sounds or internet needed - everything is generated by the code.

## Install & run (Windows)
1. Install Python 3.9+ from python.org (tick **"Add Python to PATH"**).
2. Double-click **run.bat** (it installs pygame automatically the first time).

Manual way:
```
pip install -r requirements.txt
python main.py
```

## Run in VS Code
1. File > Open Folder > select the `BubbleShooter` folder.
2. Install the "Python" extension, press `Ctrl+Shift+P` > *Python: Select Interpreter*.
3. Open a terminal (`Ctrl+``) and run `pip install -r requirements.txt`.
4. Open `main.py` and press the Run (play) button, or `F5`.

## Make a Windows EXE (PyInstaller)
Double-click **build_exe.bat**, or run:
```
pip install pyinstaller
pyinstaller --noconsole --onefile --name BubbleShooter --add-data "assets;assets" main.py
```
Your game is `dist\BubbleShooter.exe`. Progress is saved in a `data` folder next to the exe.

## Rules
- Match 3+ same-colour bubbles to pop them; bubbles cut off from the ceiling fall.
- Gray **stone** bubbles can't be matched (appear from level 31).
- Win by clearing all coloured bubbles. Lose if you run out of shots or bubbles reach the red dashed line.
- Levels 1-5 have unlimited shots; later levels have a shot limit that tightens as you progress.
- Stars: fewer shots = more stars (targets are shown on the left panel).
- Every 10th level is a **Boss level** (more colours, stones, tighter shots).

## Power-ups (unlocked progressively, +2 on first unlock, +1 random per win)
Bomb (lvl 5) · Rainbow (10) · Lightning (20) · +5 Shots (30) · Fire (40) · Slow-Mo (50)

## Project structure
```
main.py            entry point          run.bat / build_exe.bat
game/app.py        window, scaling, fade transitions
game/scenes.py     main menu, level select, settings, how-to-play
game/gameplay.py   in-level logic, HUD, pause / victory / game-over
game/physics.py    hex grid, collisions, matching, falling bubbles
game/levels.py     100 generated levels + fairness bot (shot limits)
game/powerups.py   power-up effects     game/shooter.py   cannon + projectile
game/sprites.py    glossy bubble art    game/effects.py   particles
game/background.py animated background  game/ui.py        buttons, sliders, text
game/audio.py      synthesised sound    game/save_system.py  JSON progress
tests/             test_levels.py (all 100 levels solvable) + smoke_test.py
data/progress.json saved progress
```

## Fairness check
`python tests/test_levels.py` builds all 100 levels and plays each with a bot (including a sloppy bot):
every level has a unique layout and is completable within its shot limit.
